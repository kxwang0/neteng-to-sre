Day 29：函数四要素 + 参数

知识点（逐个在交互模式里试，别只看）：
四要素：def 定义、参数（输入）、return（输出）、docstring（说明书）
默认参数：def collect(host, device_type="huawei")——调用时不传就用默认值
关键字参数：collect(host="192.168.x.x", device_type="hp_comware")——指名道姓传参，顺序随意

**kwargs 你早就在用：ConnectHandler(**dev) 就是把字典 dev 拆包成一堆关键字参数。在交互模式里跑一下感受它：

def demo(**kwargs):
    print(kwargs)

demo(host="1.1.1.1", username="netops")   # 打印出的就是字典
d = {"host": "1.1.1.1", "username": "netops"}
demo(**d)                                  # 和上面完全等价

print 和 return 的本质区别：print 是给人看的，数据出了函数就没了；return 是把数据交回调用方，可以继续传递、存文件、再加工。工具脚本要"数据在函数之间流动"。

Day 30：实战——把 Day 24 的采集脚本重构成函数版

新建 day30_collect.py，照这个结构写（理解后自己敲，别复制）：

from netmiko import ConnectHandler
from getpass import getpass

def collect(host, username, password, commands, device_type="huawei"):
    """连接设备，批量执行命令，返回 {命令: 输出} 字典。"""
    dev = {
        "device_type": device_type,
        "host": host,
        "username": username,
        "password": password,
    }
    result = {}
    conn = ConnectHandler(**dev)
    for cmd in commands:
        result[cmd] = conn.send_command(cmd)
    conn.disconnect()
    return result

def save_report(data, filename):
    """把 {命令: 输出} 字典写入一个汇总文件。"""
    with open(filename, "w") as f:
        for cmd, output in data.items():
            f.write(f"===== {cmd} =====\n{output}\n\n")

if __name__ == "__main__":
    cmds = ["display version", "display device", "display interface brief"]
    data = collect("192.168.x.x", "netops", getpass("输入设备密码: "), cmds)
    save_report(data, "R1_采集汇总.txt")
    print("完成")

跑通标志：行为和 Day 24 一模一样，但代码变成了三块可复用的零件。if __name__ == "__main__": 先记住写法，Day 36 讲原理。

2.验收
(1)print 和 return 的区别？为什么采集函数要 return 而不是直接 print？
答:print 只在屏幕上一闪而过，数据无法复用；return 把数据交回调用方，能继续传参、存盘、加工。工具的价值在"数据流动"，不在"屏幕输出"

(2)ConnectHandler(**dev) 里的 ** 是什么意思？
答:把字典拆包成关键字参数，等价于 ConnectHandler(device_type=..., host=..., ...) 逐个写出来

(3)默认参数 device_type="huawei" 带来什么好处？
答:常见值不用每次传；要连 H3C 时传 device_type="hp_comware" 即可，函数本身不用改

(4)docstring 给谁看？在哪能看到？
答:给三个月后的自己和协作的同事看；help(函数名) 和 Cursor 里鼠标悬停提示显示的都是它

(5)函数里定义的变量，函数外为什么访问不到？
答:函数内定义的是局部变量，作用域只在函数内——这是保护机制：函数内部的临时变量不会污染外部，外部数据靠参数进、靠 return 出
