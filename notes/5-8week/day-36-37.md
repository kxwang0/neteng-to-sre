Day 36：四个概念一天拿下
class：模板。网工类比：类 = 配置模板，对象 = 按模板配出来的每台具体设备

__init__：创建实例时自动执行一次，负责把初始数据绑到实例上

self：当前这个实例自己；self.host 就是"这台设备自己的 host"

方法：定义在类里的函数，第一个参数永远是 self

交互模式里先玩最小例子：

class Device:
    def __init__(self, host, device_type="huawei"):
        self.host = host
        self.device_type = device_type

    def show(self):
        print(f"{self.host} ({self.device_type})")

r1 = Device("192.168.x.11")
r2 = Device("192.168.x.12", "hp_comware")
r1.show()   # 各是各的数据，互不干扰
r2.show()

Day 37：实战——把 Netmiko 连接封装进 Device 类

from netmiko import ConnectHandler

class Device:
    def __init__(self, host, username, password, device_type="huawei"):
        self.host = host
        self.username = username
        self.password = password
        self.device_type = device_type
        self.conn = None          # 连接先占个位

    def connect(self):
        self.conn = ConnectHandler(
            device_type=self.device_type, host=self.host,
            username=self.username, password=self.password,
        )

    def run(self, cmd):
        return self.conn.send_command(cmd)

    def close(self):
        if self.conn:
            self.conn.disconnect()

r1 = Device("192.168.x.x", "netops", "密码")
r1.connect()
print(r1.run("display version"))
r1.close()

关键理解：self.conn 存成实例属性而不是 connect() 里的局部变量，是为了让 connect/run/close 三个方法共享同一条连接——局部变量方法一返回就没了。

顺带揭晓 if __name__ == "__main__":：一个 .py 文件既能直接运行、也能被别人 import。这行的意思是"只有直接运行时才执行下面的代码"——被 import 时只提供函数和类，不自动跑流程。

2.验收
(1)self 是什么？
答:当前实例自己；方法里通过 self.xxx 访问"这台设备自己的"数据，多个实例各存各的互不干扰

(2)__init__ 什么时候被调用？
答:创建实例那一刻自动调用一次（Device(...) 执行时），负责初始化

(3)为什么 conn 要存成 self.conn 而不是 connect 方法里的局部变量？
答:局部变量方法返回即销毁；存到 self 上，多个方法才能共享同一条 SSH 连接，connect 一次、run 多次、最后 close

(4)用网工类比说一遍类和对象的关系？
答:类 = 配置模板/设备型号（一份），对象 = 按模板实例化出来的每台设备（无数份）；改模板影响未来所有实例，改实例不影响模板

(5)什么时候该把一堆函数升级成类？
答:当一堆函数反复传递同几个参数（host/username/conn…）时——说明这些数据天生是一伙的，该捆成对象了
