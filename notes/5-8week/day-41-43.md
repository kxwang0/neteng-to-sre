- **Filldown**：让某个字段的值"向下填充"。比如 OSPF 邻居表，区域号只在块首出现一次，但每一行记录都要带上它

**Day 44：ntc-templates——站在社区的肩膀上**

全世界工程师写好的几千个现成模板，装上就能用：

```bash
python3.12 -m pip install ntc-templates -i https://pypi.tuna.tsinghua.edu.cn/simple

echo 'export NET_TEXTFSM=/usr/local/python3.12/lib/python3.12/site-packages/ntc_templates/templates' >> ~/.bashrc
```

用法就一个参数：

```python
result = conn.send_command("display interface brief", use_textfsm=True)

```

**Day 45：实战——健康检查小工具**

用解析结果干件真事：扫描设备所有接口/邻居，输出"异常清单"：

```python
result = conn.send_command("display ip interface brief", use_textfsm=True)
for row in result:
    # 字段名以模板为准，先 print(result[0]) 看结构
    if row.get("protocol") == "down" or row.get("physical") == "down":

```

2.验收
(1)`-> Record` 在模板里的作用？
答:把当前已捕获的各 Value 存成一行记录——表格里的一行

(2)Filldown 解决什么问题？
答:跨行共用字段：某字段只在块首出现一次（如 OSPF 的区域号），Filldown 让后续每行记录都自动带上它

(3)ntc-templates 的本质是什么？使用前提是什么？
答:社区维护的现成 TextFSM 模板库；前提是设备回显格式与模板开发时的版本一致——换大版本可能失配，所以用前先小样本验证

(4)`use_textfsm=True` 背后 Netmiko 做了什么？没命中模板时返回什么？
答:按 device_type + 命令名去 NET_TEXTFSM 指向的模板库 index 里查模板，命中则返回解析后的字典列表；没命中返回原始字符串

(5)模板匹配不上时怎么排查？
答:先看 NET_TEXTFSM 环境变量指对没有；再 grep index 确认模板存在；最后把真实回显和模板规则逐行对——失配元凶九成是空格和列宽
