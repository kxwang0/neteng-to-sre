1.验收

(1)函数为什么要 return 而不是 print？
答:return 让数据在函数间流动、可被复用和再加工；print 只是屏幕输出，数据出了函数就消失

(2)正则 \d+(\.\d+){3} 匹配什么？
答：一个 IPv4 地址（三段 \.\d+ 重复三次加开头一段数字，如 192.168.1.1）

(3)logging 比 print 强在哪三点？
答：时间戳还原时间线；分级控制输出详略不用删代码；可同时落盘和打屏

(4)argparse 里 required=True 和 default= 的区别？
答:required 不传则报错退出；default 不传则用默认值

(5)self 是什么？__init__ 什么时候执行？
答:self 是当前实例自身，方法里靠它访问实例自己的数据；__init__ 在创建实例时自动执行一次，负责初始化

(6)采集类任务为什么用线程池就够，不用多进程？
答:瓶颈在 I/O 等待不在计算，线程等回包时让出执行权即可并发；GIL 只限制多线程的并行计算，不影响 I/O 并发

(7)use_textfsm=True 生效的前提是什么？
答:设置了 NET_TEXTFSM 环境变量指向模板库，且库里有该 device_type + 命令对应的模板

(8)"模板 + 数据 = 配置"在 DevOps 生态里的亲戚举两个？
答:Ansible template 模块、Helm values+模板、Terraform templatefile（举出两个即可）

(9)merge 冲突的三块标记分别是什么？
答:<<<<<<< 到 ======= 是当前分支内容，======= 到 >>>>>>> 是合入分支内容，标记行本身都要删除

(10)为什么公共分支上禁止 rebase？
答:rebase 改写提交历史（哈希全变），公共分支上别人基于旧历史的工作会全部错乱——就像把现网设备的配置基线悄悄换了版本
