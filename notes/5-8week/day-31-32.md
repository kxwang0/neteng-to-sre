Day 31：re 模块基础
import re
核心三板斧，每个都在交互模式里试熟：

text = "GigabitEthernet0/0/1    up    up    192.168.1.1"

re.search(r"\d+\.\d+\.\d+\.\d+", text)      # 找第一个 IP，返回 Match 对象
re.findall(r"up|down", text)                 # 找所有命中，返回列表
m = re.search(r"^(\S+)\s+(up|down)", text)   # () 分组：圈出要抠的部分
m.group(0)   # 整个匹配
m.group(1)   # 第一个括号：接口名
m.group(2)   # 第二个括号：物理状态

元字符小抄（就这几个，够用到下个月）：\d 数字、\w 字母数字下划线、\s 空白、. 任意字符、* 零或多个、+ 一或多个、? 零或一个、^ 行首、$ 行尾、[^x] 非 x。

铁律：正则一律写成原始字符串 r"..."——不加 r，\d 的反斜杠会被 Python 字符串转义吃掉，出灵异问题。

Day 32：实战——解析真实设备回显
连上 R1，从 display interface brief 里把所有 UP 的接口抠出来：

import re
from netmiko import ConnectHandler
from getpass import getpass

conn = ConnectHandler(device_type="huawei", host="192.168.x.x",
                      username="netops", password=getpass("输入设备密码: "))
output = conn.send_command("display interface brief")
conn.disconnect()

for line in output.splitlines():
    m = re.search(r"^(\S+)\s+(up|down)\s+(up|down)", line)
    if m and m.group(2) == "up":
        print(f"UP 的接口: {m.group(1)}")

再抠一个版本号（先 print(output) 看一眼真实格式，再调正则——正则是对着真实回显调出来的，不是背出来的）：

ver = conn.send_command("display version")   # 重连一次或合并到上面
m = re.search(r"Version\s+([\d.\w()]+)", ver)
print(m.group(1) if m else "未匹配，打印回显检查格式")

2.验收
(1)\d 和 \d+ 的区别？
答:\d 匹配一个数字；\d+ 匹配一个或多个连续数字（如 \d 只能匹配 1，\d+ 能匹配 192）

(2)分组的作用？m.group(0) 和 m.group(1) 各是什么？
答:() 把要提取的部分圈出来；group(0) 是整段匹配文本，group(1) 是第一个括号圈住的内容

(3)re.search 和 re.findall 的区别？
答:search 只找第一个命中、返回 Match 对象（可再取分组）；findall 返回所有命中组成的列表

(4)什么时候用 re，什么时候用 TextFSM？
答:抠单个字段（版本号、某个计数器）用 re 轻巧；把整张 display 表格变成结构化数据用 TextFSM——Day 41 再深入

(5)正则表达式为什么一律加 r 前缀？
答:防止 \d、\w 里的反斜杠被 Python 字符串转义规则吃掉；原始字符串里反斜杠就是反斜杠本身
