Day 18：列表与字典——网工数据的天生形态
Python
# 设备清单 = 字典的列表（以后所有自动化项目都长这样）
devices = [
    {"name": "sw1", "ip": "192.168.1.1", "vendor": "huawei"},
    {"name": "sw2", "ip": "192.168.1.2", "vendor": "h3c"},
]
print(devices[0]["ip"])                 # 取第 1 台的 IP
devices.append({"name": "sw3", "ip": "192.168.1.3", "vendor": "huawei"})   # 追加
for dev in devices:                     # 遍历
    print(dev["name"], dev.get("ip"))   # .get() 取值，键不存在时返回 None 而不是报错
len(devices)                            # 几台设备

Day 19：文件读写
Python
# 练习：解析 /etc/passwd，输出"用户名:Shell"对照表
with open("/etc/passwd") as f:          # with 打开：用完自动关闭
    for line in f:
        line = line.strip()
        if not line:
            continue
        parts = line.split(":")         # 按冒号切列（想想 awk -F:）
        print(f"{parts[0]}:{parts[6]}")

# 写入文件
with open("output.txt", "w") as f:      # "w" 覆盖写、"a" 追加写
    f.write("第一行\n")

Day 20：异常处理 + JSON 存取
Python
try:
    with open("/不存在的文件") as f:
        data = f.read()
except FileNotFoundError:
    print("文件不存在，跳过")
except PermissionError:
    print("权限不足")
finally:
    print("无论如何都会执行（收尾动作）")

import json
with open("devices.json", "w") as f:
    json.dump(devices, f, indent=2, ensure_ascii=False)   # 存
with open("devices.json") as f:
    loaded = json.load(f)                                  # 取
print(loaded[0]["name"])

2.验收
(1)列表和字典的核心区别？设备清单为什么用"字典的列表"？
答:列表有序靠下标取（[0]），字典按键取值（["ip"]）；每台设备有多个属性（name/ip/vendor），属性用字典装、多台设备用列表装

(2)with open(...) 比裸 open() 好在哪？
答:自动关闭文件（即使中途报错也会关），不会泄漏文件句柄

(3)dict.get("key") 和 dict["key"] 在键不存在时分别什么表现？
答:[] 报 KeyError 异常；.get() 返回 None（或你指定的默认值）——不确定键在不在就用 .get()

(4)try/except 的执行流程？finally 什么时候跑？
答:try 里出错立即跳到匹配的 except 处理，没出错则跳过 except；finally 无论出不出错都执行（适合收尾）

(5)JSON 存和取各用哪个函数？
答:存 json.dump()、取 json.load()
