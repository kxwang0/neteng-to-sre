### Day 67–70 详细手册：实战——备份工具 API 化（Day 67–69 每天约 2 小时，Day 70 复盘）

> 把第 8 周的项目 v2 搬进 Web 世界：**POST 触发备份，GET 查询结果**。

**Day 67：改造思路**

原则一句话：**Web 层只是壳，业务函数原样复用**。把 v2 项目里的 `backup_one()` / `load_devices()` import 进来，路由函数只做"接参 → 调函数 → 包返回"。这就是分层：HTTP 层 / 业务层 / 设备层。

**Day 68–69：参考实现**（理解后自己写）：

```python
from fastapi import FastAPI
from getpass import getpass
import yaml

app = FastAPI(title="备份平台")
PASSWORD = getpass("设备统一密码: ")   # 服务启动时输入一次

def load_devices(path="devices.yaml"):
    with open(path) as f:
        return yaml.safe_load(f)

@app.get("/devices")
def list_devices():
    devs = load_devices()
    return [{"name": d["name"], "host": d["host"]} for d in devs]

@app.post("/backup/{name}")
def backup_one_api(name: str):
    devs = {d["name"]: d for d in load_devices()}
    if name not in devs:
        return {"ok": False, "msg": f"设备 {name} 不在清单里"}
    d = devs[name]
    try:
        # 复用项目 v2 的采集逻辑（这里简写）
        from netmiko import ConnectHandler
        conn = ConnectHandler(device_type=d.get("device_type", "huawei"),
                              host=d["host"], username=d["username"],
                              password=PASSWORD)
        cfg = conn.send_command("display current-configuration")
        conn.disconnect()
        return {"ok": True, "device": name, "bytes": len(cfg)}
    except Exception as e:
        return {"ok": False, "device": name, "msg": str(e)}
```

验证三板斧：`curl 127.0.0.1:8000/devices` 看清单 → `/docs` 页面点 POST 触发一次备份 → 从 Windows 浏览器访问 `http://<Rocky-IP>:8000/docs` 确认对外可达。

2.验收
(1)"Web 层只是壳"具体指什么？
答:路由函数只做接参、调业务函数、包装返回三层皮；业务逻辑（连设备、采集）一行不改原样复用——分层让 Web 化不动核心业务

(2)服务启动时用 getpass 收密码的做法，相对配置文件存密码的优劣？
答:优：密码不落盘不进仓库；劣：服务重启要人工输一次——学习期可接受，生产会用密钥管理服务（这本身就是个认知点）

(3)接口里为什么要 try/except 把异常转成 JSON 返回？
答:异常不拦就会以 HTTP 500 堆栈的形式炸给调用方；转成 `{"ok": false, "msg": ...}` 是 API 的基本修养——**错误也是接口契约的一部分**

(4)从 Windows 浏览器访问 Rocky 的 8000 端口不通，按什么顺序查？
答:服务是否在跑（`ss -tlnp | grep 8000`）→ 监听的是不是 0.0.0.0 → Rocky 防火墙（`sudo firewall-cmd --add-port=8000/tcp`，或学习期 `sudo systemctl stop firewalld`）→ VMware NAT 网是否互通

(5)这个月做的和"真产品"之间还差哪三块？
答:异步任务队列（长任务不阻塞 HTTP）、数据库（结果持久化）、鉴权（谁能调）——都记进 backlog
