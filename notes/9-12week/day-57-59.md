**Day 58：第一个任务——三行跑通并发采集**

```python
from getpass import getpass
from nornir import InitNornir
from nornir_netmiko.tasks import netmiko_send_command
from nornir_utils.plugins.functions import print_result

nr = InitNornir(config_file="config.yaml")

# 密码不落盘：统一运行时注入（守住"密码不进仓库"的红线）
pw = getpass("设备统一密码: ")
for host in nr.inventory.hosts.values():
    host.password = pw

result = nr.run(task=netmiko_send_command, command_string="display version")
print_result(result)
```

对比着理解你获得了什么：设备清单管理（YAML）、线程池并发（runner）、逐台结果归集（result）——全是内置的。hosts.yaml 里加三台设备，一次 `nr.run` 全部采完，**一行并发代码都不用写**。

**Day 59：过滤——指哪打哪**

```python
from nornir.core.filter import F

only_huawei = nr.filter(F(platform="huawei"))          # 只挑华为设备
result = only_huawei.run(task=netmiko_send_command, command_string="display version")
```

`groups.yaml` 按角色分组（core/edge），`F(groups__contains="edge")` 只操作边缘组——清单越大，过滤越值钱。

2.验收
(1)Nornir 的三个 YAML 各管什么？
答:config.yaml 是框架配置（用哪个清单插件、并发几线程）；hosts.yaml 是设备清单（主机名/IP/平台）；groups/defaults 是分组与默认值——分组继承减少重复

(2)`nr.run()` 替你做了哪三件你 Day 50 手写过的事？
答:清单解析、线程池并发、逐台结果归集（哪个成功哪个失败、各回了什么）

(3)密码为什么用运行时注入而不是写进 hosts.yaml？
答:hosts.yaml 是要进 git 的，密码写进去等于公开；运行时 getpass 注入，清单里只有结构没有秘密

(4)`F(platform="huawei")` 的作用？什么场景下值钱？
答:按属性过滤设备子集，任务只打在命中的设备上；混合厂商/分区分角色的大清单里，这是"指哪打哪"的瞄准镜

(5)学了 Nornir，Netmiko 是不是白学了？
答:恰恰相反——Nornir 的 task 底层就是 Netmiko（`nornir_netmiko`），platform 填的就是 netmiko 的 device_type。框架是壳，驱动还是你懂的那个
