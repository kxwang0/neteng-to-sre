**Day 83：综合自测**（合上文档做）：

1. Nornir 框架替你做了哪三件事？
答:清单管理（YAML 三文件）、线程池并发、逐台结果归集

2. Netmiko / Scrapli / Nornir 各在什么层？
答:Netmiko/Scrapli 是驱动层（连单台设备）；Nornir 是框架层（编排多台，底层调驱动）

3. FastAPI 里 uvicorn 的角色？`/docs` 哪来的？
答:uvicorn 是 ASGI 服务器，负责监听端口收发 HTTP；/docs 是 FastAPI 根据路由和类型注解自动生成的 Swagger 交互文档

4. "Web 层只是壳"怎么理解？
答:路由只做接参→调业务函数→包装返回，业务逻辑原样复用；分层让"API 化"不动核心业务

5. 规则的 forbid / require 判定逻辑？
答:forbid：正则命中即违规；require：正则不命中即违规

6. 为什么先落 JSON 再渲染 HTML？
答:JSON 是机器可读的中间层，HTML 只是它的一种渲染——数据不锁死在展示层

7. `F(platform="huawei")` 干什么用？
答:按属性过滤设备子集，任务只下发到命中的设备上

8. 单台设备扫描失败应该怎么处理？
答:try/except 记 error 日志、该设备单独标记"扫描失败"，绝不中断整批

9. 密码运行时注入解决了什么问题？
答:清单文件要进 git，密码写进去等于公开；运行时注入让仓库里只有结构没有秘密

10. 本月三个项目的递进关系是什么？
答:v2 备份工具（单机命令行）→ 备份 API（可被 HTTP 调用的服务）→ 合规检查器（从"采集"升级到"分析判断"）——工具 → 服务 → 产品雏形
