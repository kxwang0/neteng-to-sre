2.验收
(1)`var.xxx` / `资源类型.名字.属性` / `output` 三种引用各是什么？
答:var 是入参（可调）；资源引用是把别的资源的属性接进来（自动建立依赖）；output 是把结果吐出来（给人看、给下游用）

(2)`internet_max_bandwidth_out = 1` 的作用？为 0 会怎样？
答:出方向带宽大于 0 才分配公网 IP；为 0 则纯内网实例，SSH 不上去

(3)`sensitive = true` 防的是什么？
答:防止值被打印在 plan/apply 的终端输出和日志里——敏感变量不该裸奔在屏幕上

(4)资源间的引用关系给 Terraform 带来什么能力？
答:自动拓扑排序：创建按依赖正序、销毁反序，不用你操心谁先谁后

(5)apply 报"该可用区无此规格"怎么办？
答:正常情况：换有库存的可用区（改 var.zone）或换规格——按量实例的库存是实时的，这不是你的配置错误
