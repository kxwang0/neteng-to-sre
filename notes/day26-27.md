本月毕业作品：把前三周的所有零件组装成一个真能用的工具。
项目需求：
设备清单写在 devices.json（Day 20 的技能）
逐台登录，抓取 display current-configuration
配置存为 backups/设备名_日期.txt，同时保留一份 设备名_latest.txt
与上一次备份做 diff，有变更则打印差异行数，无变更打印"无变化"
单台失败不中断（try/except），最后汇总成功/失败清单
代码框架（补全留白部分，别照抄）：
Python
import json, difflib, os
from datetime import date
from netmiko import ConnectHandler
from getpass import getpass

os.makedirs("backups", exist_ok=True)
today = date.today().isoformat()
password = getpass("设备统一密码: ")

with open("devices.json") as f:
    devices = json.load(f)

ok, failed = [], []
for dev in devices:
    try:
        conn = ConnectHandler(
            device_type=dev["device_type"], host=dev["ip"],
            username=dev["username"], password=password, timeout=15)
        config = conn.send_command("display current-configuration")
        conn.disconnect()

        latest = f"backups/{dev['name']}_latest.txt"
        old = open(latest).read().splitlines() if os.path.exists(latest) else []
        diff = list(difflib.unified_diff(old, config.splitlines(), lineterm=""))

        with open(f"backups/{dev['name']}_{today}.txt", "w") as f:
            f.write(config)
        with open(latest, "w") as f:
            f.write(config)

        print(f"[{dev['name']}] 备份完成，变更 {len(diff)} 行" if diff else f"[{dev['name']}] 无变化")
        ok.append(dev["name"])
    except Exception as e:
        print(f"[{dev['name']}] 失败：{e}")
        failed.append(dev["name"])

print(f"\n成功 {len(ok)} 台：{ok}")
print(f"失败 {len(failed)} 台：{failed}")
两天分工：Day 26 跑通"登录→采集→存档"主流程；Day 27 加 diff 对比、异常容错、汇总报告，然后进仓库打卡。

2.验收
(1)为什么设备清单放 JSON 文件而不是写死在脚本里？
答:数据和代码分离：加设备改 JSON 就行，不动代码——代码是逻辑，清单是资产（以后换成 YAML/数据库/CMDB 同理）

(2)os.makedirs(..., exist_ok=True) 的 exist_ok 有什么用？
答:目录已存在时不报错直接跳过（幂等），没有则创建——脚本可以反复跑

(3)为什么单台失败要 try/except 包住而不是让脚本直接崩？
答:批量场景必须"单点失败不影响整体"：一台设备宕机不该让其余 49 台的备份全部泡汤——这是自动化工具的基本修养

(4)difflib.unified_diff 输出的是什么？为什么 diff 为空就说明无变更？
答:标准 diff 格式的差异行列表（- 删除行、+ 新增行）；两个文件逐行完全一致时 diff 自然为空

(5)这个项目距离"生产可用"还差哪三件事？
答:示例方向：①并发提速（串行改多线程/换 Nornir）②密码安全（改密钥认证/密码入库加密）③变更告警（接邮件/企业微信通知）——答出两条即过，第 2 个月会逐个实现
