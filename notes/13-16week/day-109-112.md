## Day 109–110：实战项目
### 做什么
扫描 NAT 网段 `192.168.30.1–254`，找出 **TCP 22 开放** 的主机（Rocky、EVE 相关 VM、R1/R2 等）。几秒内扫完 254 个地址，体会 goroutine 相对串行 `Dial` 的速度差。
### 运行
```bash'''
cd ~/code/neteng-to-sre/scripts/week13-16/day109-112
go run scanner.go
go build -o ssh_scan scanner.go
./ssh_scan
go build 产出单二进制，拷到别的 Linux 也能跑，不必在目标机装 Go（对比 Python 要带解释器/依赖）。

scanner.go（与仓库一致）
package main
import (
    "fmt"
    "net"
    "sync"
    "time"
)
func check(ip string, results chan<- string, wg *sync.WaitGroup) {
    defer wg.Done()
    conn, err := net.DialTimeout("tcp", ip+":22", 500*time.Millisecond)
    if err == nil {
        conn.Close()
        results <- ip
    }
}
func main() {
    var wg sync.WaitGroup
    results := make(chan string, 256)
    for i := 1; i < 255; i++ {
        wg.Add(1)
        go check(fmt.Sprintf("192.168.30.%d", i), results, &wg)
    }
    wg.Wait()
    close(results)
    for ip := range results {
        fmt.Println(ip, "SSH 开放")
    }
}
网段若不是 192.168.30.x，改 fmt.Sprintf 那一行即可。

2.验收
(1)Ansible 的 inventory 里 `ansible_connection=network_cli` 是什么意思？
答:用 SSH CLI 通道连接被管端（网络设备的连接方式，区别于 Linux 的标准 SSH 执行模式）

(2)`register` + `delegate_to: localhost` 组合解决了什么？
答:register 把设备回显存进变量；delegate 把"存文件"这步拉回控制节点执行——设备出数据、本地落盘

(3)vault 文件为什么能进公开仓库？vault 密码呢？
答:vault 内容是 AES 密文，无密码不可还原；vault 密码绝不进同一仓库（锁和钥匙分开放）

(4)幂等性是什么？连跑两次 playbook 的 `changed` 说明什么？
答:重复执行安全（结果与执行一次相同）；第二次 `changed=0` 说明已达目标状态、无需变更——幂等的直观证据

(5)role 的 defaults 目录语义？
答:放默认变量：优先级最低、最易被覆盖——"能跑、好改"的参数语义

(6)动态 inventory 的"单一事实来源"指什么？
答:设备信息只有一份权威来源（CMDB/云平台），inventory 是它的实时投影，不手工维护第二份

(7)AWX 的生态位？为什么现在不装？
答:Ansible 的 Web 管理面（定时/权限/可视化）；现代 AWX 依赖 K8s，容器阶段学完再装

(8)Go 的错误处理范式？goroutine 怎么启动？
答:错误是普通返回值，`if err != nil` 显式处理；函数前加 `go` 关键字即启动 goroutine

(9)`go build` 产物相比 Python 脚本的分发优势？
答:单二进制零依赖：目标机不用装解释器和一堆 pip 包，拷过去就跑——Python 脚本要拖家带口

(10)Ansible / Python / Go 在你工具箱里的分工（三句话）？
答:Ansible 管状态收敛和批量配置；Python 管复杂逻辑与数据处理；Go 管需要分发部署的性能型小工具
