1.今日学习内容
### Day 85–87 详细手册：架构认知、inventory 与 ad-hoc（每天约 2 小时）

> **范式转换提醒**：Netmiko/Nornir 是"我写循环去连设备"（命令式）；Ansible 是"我声明要做什么，引擎去执行"（声明式）。你不是少了活干，是升了一层。

**Day 85：装网络模块集合 + 配置文件**

```bash
ansible-galaxy collection install ansible.netcommon community.network ansible.utils
# 国内慢就多试几次，这一步卡住是网络问题不是配置问题
```

建工作目录 `~/code/ansible-lab/`，先写 `ansible.cfg`（项目级配置，省去一堆命令行参数）：

```ini
[defaults]
inventory = hosts.ini
host_key_checking = False        # 学习期关掉主机密钥确认
retry_files_enabled = False
timeout = 30
```

再写 `hosts.ini`（inventory = 设备清单，类比 Nornir 的 hosts.yaml）：

```ini
[huawei]
R1 ansible_host=192.168.x.11

[huawei:vars]
ansible_connection=ansible.netcommon.network_cli
ansible_network_os=community.network.ce
ansible_user=netops
```

四个关键变量背下来：`ansible_connection=network_cli`（走 SSH CLI 通道）、`ansible_network_os`（设备系统类型，华为填 `community.network.ce`）、`ansible_host`/`ansible_user` 见名知义。

**Day 86：ad-hoc——不写剧本先发一条命令**

```bash
ansible huawei -m community.network.ce_command -a "commands='display version'" -k
```

`-k` 表示交互式询问 SSH 密码。看到版本回显 = 链路全通。

**排障退路（重要）**：`ce_*` 模块是为华为 CloudEngine 设计的，AR 镜像上若报兼容错误，换通用模块：

```bash
ansible huawei -m ansible.netcommon.cli_command -a "command='display version'" -k
```

`cli_command` 是厂商中立的"裸发命令"模块——**专用模块不行时永远有这条退路**。

**Day 87：先对 Rocky 本机练 Linux 向模块**

Ansible 不止管网设备——它的主场是服务器。对 Rocky 练手（这也是下个月 Terraform+云的前置）：

```ini
[linux]
rocky ansible_host=127.0.0.1 ansible_user=kxwang
```

```bash
ansible linux -m ping -k                       # 不是 ICMP，是 Ansible 层的连通测试
ansible linux -m command -a "uptime" -k
ansible linux -m dnf -a "name=htop state=present" -k -K   # -K 询问 sudo 密码
```
2.验收
(1)`ansible_connection` 和 `ansible_network_os` 各管什么？
答:connection 决定用什么通道连（network_cli=SSH CLI / local / httpapi 等）；network_os 告诉 Ansible 对端是什么系统，决定参数注入方式和模块行为

(2)ad-hoc 命令里的 `-m`、`-a`、`-k`、`-K` 各是什么？
答:`-m` 指定模块、`-a` 给模块传参、`-k` 询问 SSH 密码、`-K` 询问 sudo 提权密码

(3)Ansible 管网络设备和管 Linux 服务器，连接通道有何不同？
答:网络设备走 network_cli（SSH 进 CLI 发命令）；Linux 走标准 SSH 执行模块推送的 Python 代码——对被管端的要求完全不同

(4)`ce_command` 报兼容错误时的退路是什么模块？
答:`ansible.netcommon.cli_command`（厂商中立的裸命令模块）；再不行还有 Netmiko 自定义模块兜底

(5)"声明式"和你在 Netmiko 里写的"命令式"差别一句话？
答:命令式写"怎么一步步做"，声明式写"要什么状态/结果"，执行细节交给引擎
