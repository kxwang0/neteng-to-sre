Day 23：连上设备，拿下第一条 display
Python
from netmiko import ConnectHandler
from getpass import getpass

dev = {
    "device_type": "huawei",          # 或 "hp_comware"（H3C）/ "linux"（本机兜底）
    "host": "192.168.x.x",            # 设备管理 IP
    "username": "netops",
    "password": getpass("输入设备密码: "),
}

conn = ConnectHandler(**dev)
print(conn.send_command("display version"))
conn.disconnect()
跑通标志：终端里打印出设备的版本信息。这一刻你的 Python 和网络正式会师。

Day 24：批量采集 + 落盘
Python
commands = ["display version", "display device", "display interface brief"]
for cmd in commands:
    output = conn.send_command(cmd)
    filename = cmd.replace(" ", "_") + ".txt"
    with open(filename, "w") as f:
        f.write(output)
    print(f"{cmd} 已保存到 {filename}")

Python
import textfsm

raw = conn.send_command("display interface brief")

template = """Value INTF (\S+)
Value PHY (\S+)
Value PROTO (\S+)
Value IP (\S+)

Start
  ^${INTF}\s+${PHY}\s+${PROTO}\s+${IP} -> Record
"""

with open("intf.template", "w") as f:
    f.write(template)

with open("intf.template") as t:
    table = textfsm.TextFSM(t).ParseText(raw)

print(f"{'接口':<15}{'物理':<8}{'协议':<8}IP")
for row in table:
    print(f"{row[0]:<15}{row[1]:<8}{row[2]:<8}{row[3]}")
模板语法只需记住两点：Value 名 (正则) 定义要抠的字段、Start 下每行是一条匹配规则、-> Record 表示命中就存一行。输出从"人看的回显"变成整齐表格——这就是 Day 7 说的"程序能用的数据"。

2.验收
(1)华为和 H3C 的 device_type 各填什么？
答:华为 "huawei"；H3C "hp_comware"（思科 "cisco_ios"）

(2)send_command() 和 send_config_set() 的用途区别？
答:send_command() 发查看类命令拿返回；send_config_set() 下发配置命令（自动进出配置视图）

(3)TextFSM 模板里 Value 和 Start 各管什么？
答:Value 定义要提取的字段（名字 + 正则）；Start 是起始状态，其下的匹配规则逐行扫描回显

(4)设备密码应该怎么处理？（为什么不能写死在脚本里）
答:用 getpass() 运行时输入或环境变量——写死在脚本里会随 git 提交进公开仓库（DevSecOps 红线）

(5)设备回显分页（---- More ----）需要手动处理吗？
不需要——Netmiko 按 device_type 的驱动自动处理分页（自动敲空格翻页或先关闭分页），这也是用 Netmiko 而不是裸 paramiko 的原因
